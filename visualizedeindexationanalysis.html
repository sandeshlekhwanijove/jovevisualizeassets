07

Prioritised Action Plan

Priority 1 — Highest impact
Vocabulary Diversity
Target TTR > 0.60. Audit boilerplate sections (methods, abstract, conclusions) for repeated phrasing. Vary terminology per article. Replace generic connectives ("furthermore", "in addition") with specific transitional language.
28% → 81% index rate range
Priority 2 — Strong signal
Readability Polish
Target Flesch 20–50. Break sentences longer than 30 words. Replace 3-syllable technical terms with shorter synonyms where possible. Add topic sentences to each paragraph. Aim for FK Grade 13–15 where content allows.
40% → 56% index rate range
Priority 3 — Structural
Internal Links + Titles
Increase internal link density (aim >12 per 100 words). Shorten titles to <60 characters where feasible — these index at 66.5%. Reduce H2/H3 count from 25–30 to 15–22 for better heading density per section.
39% → 60% index rate range
